# HON Environmental Equity Dashboard

Interactive GIS dashboard analyzing environmental burden, zoning, and housing equity across Seattle, Washington.

This project was developed in collaboration with **House Our Neighbors (HON)** as part of a university GIS research project focused on environmental justice and multifamily housing policy.

---

## Project Overview

This dashboard explores relationships between:

* Multifamily housing zoning
* Proposed Seattle upzones
* Environmental burden indicators
* Noise pollution
* Demographic patterns
* Respiratory health indicators

The goal of this project is to better understand whether multifamily and affordable housing are disproportionately located in areas with higher environmental burden and to evaluate how proposed zoning changes may affect environmental equity in Seattle.

## Running the Project Locally

1. Clone the repository:

```bash
git clone https://github.com/Kha50/hon-environmental-equity-dashboard.git
```

2. Open the project folder in Visual Studio Code.

3. Install the Live Server extension.

4. Right click `index.html` and select:

```text
Open with Live Server
```
